# 🍔 Food Delivery Data Analysis Using MySQL

## 📌 Project Overview

This project focuses on analyzing food delivery business data using **MySQL**. The main objective is to understand customer ordering patterns, restaurant performance, food preferences, delivery times, revenue generation, and order status.

The project uses SQL queries to extract meaningful business insights and support data-driven decision-making.

## 🎯 Project Objectives

- Analyze customer ordering patterns.
- Identify top-performing restaurants.
- Find the most popular food items.
- Calculate total revenue and average order value.
- Analyze delivery times and delayed orders.
- Identify cancelled and completed orders.
- Understand monthly sales trends.
- Analyze customer and restaurant performance.

## 🗄️ Database Design

Database Name: `food_delivery_db`

The project contains the following tables:

1. **Customers** – Stores customer information.
2. **Restaurants** – Stores restaurant details.
3. **Orders** – Stores order and delivery information.
4. **Order_Items** – Stores food items and their quantities.
